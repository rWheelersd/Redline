1. Create a folder here, such as img/events/carShow/.
2. Put the cover photo in that folder as image0.jpg (or image0.png).
   Add the remaining photos as image1.jpg, image2.jpg, and so on.
3. In js/gallery.js, add an eventLibrary entry with the event name,
   folder, and an images array listing every exact filename in order.
   The first image in the array (image0) becomes its thumbnail.
4. The Events dropdown will enable itself when at least one entry exists.
